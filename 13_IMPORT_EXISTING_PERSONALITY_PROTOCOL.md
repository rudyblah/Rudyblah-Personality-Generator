# 13 — Optional Intake Protocol for an Existing Personality

**Workspace:** Rudyblah Personality Generator. **Status:** project-source design rule.

## Intake is not automatic

The catalog starts empty. A separate character/personality reference must be explicitly selected by the user, never inferred from the Project title or another chat. No external project, Library location, drive folder, or prior conversation is available by implication.

1. Receive a user-supplied reference and, if relevant, its authoritative canon master, approvals, and source-hash receipt.
2. Assign a stable `personality_id` in a **proposed isolated catalog entry**. Do not modify the empty catalog until separately approved and a write/readback path exists.
3. Map behavior, identity, confirmed facts, user-authorized defaults, provisional claims, unresolved creative work and private data into **different records**. Label each claim's source and status.
4. Preserve the source's approval policy. Never treat the act of importing or transcribing content as a new approval or a verified persistent write.
5. Place private or controlled-test data outside ordinary runtime and BLIND exports. No hidden-value leakage through indirect text.
6. For both modes, maintain internal canon and optional visual-identity prompts. Only INTERMEDIATED builds may create external character-persona exports, and only when requested by the destination contract.
7. Keep conversation branches empty until the user designates one. Do not assume private thoughts, third-party reactions or external submissions.
8. Independently reopen and verify every artifact and receipt after any authorized persistence operation. Otherwise label it `PREVIEW_ONLY / NOT INSTALLED`.

## Intake acceptance

A human-readable character file can be **sufficient as source material** while remaining **insufficient as a drop-in runtime import**. Missing configuration fields, approval queue, unique IDs, structural provenance, images/prompts or storage proof must be listed as gaps, not fabricated. An incomplete import remains review-only.
